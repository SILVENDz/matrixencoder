  • A letter-to-number key (included on the right)
  • A matrix key (also on the right!)
  • Understand matrix multiplication
  • Understand how to take the inverse of a matrix
  • Lots of patience...
  • For example, lets say I wanted to send my buddy a message without anyone else being able to read it. For simplicity, my message will be "HELLO".
  • Using the key on the right, I will convert the message into numerical form. In this case, "HELLO" will become "8 5 12 12 15".
  • Then, you will create 2 number matrices (1 row, 2 columns) using the numbers derived from the message. If there is an odd number of letters, you will add a _ (which tanslated to a 0)
  • In this case, your matrix will look like this: [8 5] [12 12] [15 0]
  • Then, you will multiply the message matrix by the matrix key (on the right). The result will be a new matrix that is your encoded message!
